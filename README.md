## Software Description
AI Job Coach is a web application designed to help college students prepare for internships and jobs. The app allows users to enter a job description along with their resume and cover letter. Using AI, AI Job Coach analyzes the student’s documents and provides targeted feedback based on the job requirements, helping students improve alignment, wording, and overall quality. This helps students practice realistic interview scenarios and improve confidence.

AI Job Coach will store user account data, resumes, cover letters using a supabase database. The application will be built using HTML, CSS, and JavaScript, with Node.js and Express handling backend logic.
